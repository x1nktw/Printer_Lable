LabelPrint FrontPad Bridge 1.3.5 — установка

1. Запустите LabelPrint Pro 0.8.0+ (должен слушать webhook, обычно http://127.0.0.1:8765).
2. Откройте Chrome или Edge:
   chrome://extensions
   edge://extensions
3. Включите «Режим разработчика».
4. «Загрузить распакованное расширение» → выберите эту папку:
   extensions\frontpad-bridge
5. Откройте FrontPad, при необходимости перезагрузите вкладку.
6. URL webhook: LabelPrint → Настройки → Общие.

После обновления LabelPrint Pro: на странице расширений нажмите «Обновить»
у FrontPad Bridge (или удалите и загрузите папку снова).

Отдельный архив на GitHub Releases: frontpad-bridge-1.3.5.zip

Подробнее: docs/FRONTPAD_KITCHEN.md и README.md в этой папке.
