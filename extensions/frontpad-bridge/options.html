LabelPrint FrontPad Bridge

Расширение перехватывает сохранение заказа на сайте FrontPad (order.php) и отправляет JSON с позициями на локальный webhook LabelPrint Pro.

Должен совпадать с полем «Webhook listen URL» в настройках LabelPrint. Приложение должно быть запущено.

Выключите, чтобы временно не слать заказы.

Установка

  1. Chrome/Edge → chrome://extensions / edge://extensions
  2. Режим разработчика → «Загрузить распакованное»
  3. Папка extensions/frontpad-bridge в репозитории LabelPrint
  4. Откройте FrontPad, сохраните заказ — статус смотрите в иконке расширения
