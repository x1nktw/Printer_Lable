# FrontPad → LabelPrint Pro

Совместимо с **LabelPrint Pro 1.1.0+** и **FrontPad Bridge 1.4.4**.

## Shop API

**Не используем.** Методы `get_products`, `new_order` и остальной internet-shop API отключены.  
Каталог ведётся локально (ручной ввод / CSV). Секрет и Base URL в настройках не нужны.

---

## Поток заказов

1. Расширение **FrontPad Bridge 1.4.4** (`extensions/frontpad-bridge`) перехватывает `order.php` в браузере  
2. POST JSON на локальный webhook LabelPrint (`http://127.0.0.1:8765/` по умолчанию)  
3. Автоимпорт в БД + обновление списка (+ автопечать при включении)  
4. Heartbeat Bridge → индикатор на **Главной** («Статус системы») и цвет кнопки **LP**

Дополнительно: JSON-файлы в inbox (`%LocalAppData%\LabelPrintPro\orders-inbox`) — кнопка **Inbox** / **Пример** на странице **Заказы**.

Webhook URL: **Настройки → Общие** → FrontPad Bridge.

На странице **Заказы** выберите **принтер** (и шаблон) — ручная и автопечать идут на него (`OrdersPrintPrinterId`).

Иконки добавок на кухонной этикетке: только пользовательские PNG в **Каталог → Добавки** (название как в FrontPad). Без файла иконка на этикетке не рисуется.

### Установка Bridge 1.4.4

В релизе / publish / установщике расширение уже лежит в `extensions/frontpad-bridge/` (рядом с `LabelPrint.UI.exe` / в Velopack — в `current\extensions\…`).  
Отдельный артефакт релиза: `frontpad-bridge-1.4.4.zip`.

Chrome/Edge → Режим разработчика → **Загрузить распакованное** → эта папка.  
После обновления файлов — кнопка **Обновить** у расширения и жёсткая перезагрузка вкладки FrontPad (`Ctrl+Shift+R`).  
На FrontPad: кнопка **LP** (слева от ФР) → **Подключить**.  
См. `INSTALL.txt` и [README расширения](../extensions/frontpad-bridge/README.md).

### Кнопка LP и подключение (1.4+)

- Зелёная `#6AC579` — связь с LabelPrint есть; красная `#E74C3C` — нет.
- Окно: IP/Port, «Подключать автоматически», тест webhook, тёмная тема FrontPad.
- Popup расширения — подсказка нажать LP (основные настройки в modal на странице).

### Тёмная тема FrontPad (1.3.7+)

В окне LP / popup / настройках расширения: галочка **«Тёмная тема FrontPad»**.  
Тёплая палитра (в духе Claude), без CSS invert; статусные цвета кухни сохраняются в приглушённом виде.  
Тема применяется ко всем вкладкам `*.frontpad.ru` (включая iframe). UI кнопки LP и overlay Bridge не перекрашиваются.

### Добавки (модификаторы)

FrontPad шлёт добавки отдельными строками `positions` с `parent` = индекс блюда (часто `"0"`).  
Bridge **склеивает** их в одну позицию заказа:

- `name` — только блюдо  
- `addons` / `comment` — список добавок  

На печати шаблон **«Кухня чек 40×58»** рисует блок **ДОБАВКИ** с иконками (не отдельные этикетки на каждую добавку).  
В редакторе шаблонов: двойной клик по элементу **AddonsKitchen** — правка layout (заголовок, строки, empty-state).

Парсер (1.3.5–1.3.6): запятые внутри названий добавок («Капуста, томаты») не режут заказ на ложные «Позиция N».

### Схема JSON заказа

```json
{
  "externalOrderId": "14320522",
  "number": "65501",
  "customerName": "Зал",
  "comment": "Без лука",
  "statusCode": "new",
  "orderedAt": "2026-08-01T12:00:00+05:00",
  "items": [
    {
      "sku": "303984",
      "name": "Классика",
      "quantity": 1,
      "price": 340,
      "addons": ["Бекон", "Картофель"],
      "comment": "Бекон\nКартофель"
    }
  ]
}
```

`sku` из Bridge часто = внутренний `productID`; сопоставление с каталогом — по SKU / имени (без sync через API).

### Этикетка кухни

- Пресет: **Кухня чек 40×58** (вертикаль; ширина ленты в принтере = **40** мм).  
- Как настроить принтер: [PRINTERS.md](PRINTERS.md).  
- Дата/время: **Настройки → Общие** → Realtime/ручная; на этикетке — из контекста печати.
- **qty:** количество позиции разворачивается в отдельные этикетки с индексами **1/N…N/N** (не одна этикетка с copies=qty). Пример: Burger×2 + Fries×1 → три этикетки 1/3, 2/3, 3/3.

Установка расширения: [extensions/frontpad-bridge/README.md](../extensions/frontpad-bridge/README.md).
