# LabelPrint Pro 1.1.0 — заметки к релизу

**Дата:** 2026-08-10  
**Состав:** приложение **1.1.0** · FrontPad Bridge **1.4.4**

Кратко: кухня печатает qty отдельными этикетками, на Заказах выбирается принтер, Bridge подключается кнопкой **LP** на странице FrontPad, в редакторе можно править layout блока добавок, темы UI расширены, встроенные иконки товаров/добавок убраны.

Полный список изменений: [CHANGELOG.md](../CHANGELOG.md#110---2026-08-10).

## Обновление с 1.0.x

1. **Настройки → Система → Обновить** или новый Setup — применится миграция `OrdersPrintPrinterId`.
2. Обновить Bridge до **1.4.4** (`chrome://extensions` → Обновить) и жёстко перезагрузить FrontPad (`Ctrl+Shift+R`).
3. На FrontPad: **LP → Подключить** (иконка зелёная при связи).
4. На странице **Заказы** выбрать принтер (и шаблон) — это влияет на автопечать.
5. При необходимости загрузить PNG иконок в **Каталог → Добавки** / товары маркировки.

С **0.8.x (Inno):** однократно поставить `LabelPrintPro-win-Setup.exe`, затем как выше.

## На что обратить внимание оператору

| Изменение | Что сделать |
|-----------|-------------|
| qty 2 → две этикетки **1/N…N/N** | Больше расход ленты; индексы на чеке другие |
| Нет встроенных иконок добавок | Загрузить свои PNG в каталог |
| Bridge UX через кнопку **LP** | Не полагаться только на старый popup |
| Принтер на **Заказах** | Без выбора автопечать может идти не туда |

## Проверка после установки

- [ ] Главная: статус Bridge / принтер / очередь без ошибок
- [ ] FrontPad: LP зелёная, сохранение заказа → inbox / список Заказов
- [ ] Автопечать на выбранный принтер; qty≥2 даёт несколько этикеток с N/M
- [ ] Редактор: двойной клик по AddonsKitchen → правки layout → превью печати
- [ ] Темы UI переключаются; тёмная тема FrontPad не ломает кнопку LP
- [ ] Velopack: Настройки → Система видит канал обновлений (после публикации релиза)
