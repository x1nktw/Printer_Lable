# Принтеры в LabelPrint Pro

Как добавить принтер и что означают протоколы / поле «Подключение».

## Быстрый старт (без железа)

1. Откройте раздел **Принтеры**.
2. Нажмите **Добавить виртуальный**.
3. Проверьте:
   - **Протокол:** `File`
   - **Название:** например `Виртуальный (PNG)`
   - **Подключение:** можно оставить пустым  
     (файлы уйдут в `%LocalAppData%\LabelPrintPro\prints\`)
   - **Ширина бумаги:** `40` или `58` мм — под ваш шаблон
   - **DPI:** обычно `203` для термопринтеров
   - включите **Принтер по умолчанию**, если это первый принтер
4. **Сохранить**.
5. В **Каталоге** / **Сырьё** / **Заказах** выберите этот принтер и нажмите **Печать**.
6. Результат — PNG в папке `prints` (удобно проверять шаблон «Кухня чек 40×58» без железа).

## Реальный принтер Windows (USB / драйвер)

Подходит, если принтер уже виден в Windows («Принтеры и сканеры»).

1. Установите драйвер производителя, напечатайте тестовую страницу из Windows.
2. Скопируйте **точное имя** очереди:
   - Параметры Windows → Bluetooth и устройства → Принтеры и сканеры → имя устройства  
   - или `Win + R` → `control printers`
3. В LabelPrint → **Принтеры** → **Добавить виртуальный** (откроет форму) и измените поля:
   - **Протокол:** `Windows`
   - **Подключение:** *точное* имя очереди Windows, например `Xprinter XP-365B`  
     (регистр не важен, пробелы и символы должны совпадать)
   - **Ширина:** `40` или `58` мм
   - **DPI:** `203` (часто) или `300`, если так в драйвере
4. Сохранить → **По умолчанию**.
5. Печать из каталога/заказов.

Если печать падает с «printer was not found» — имя в **Подключение** не совпадает с очередью Windows.

## Сетевой термопринтер (TSPL / CPCL)

Для принтеров с Ethernet/Wi‑Fi, принимающих сырой язык этикеток.

| Протокол | Когда выбирать | Подключение |
|----------|----------------|-------------|
| `Tspl`   | Xprinter / многие 203 DPI «TSPL» | `host:port`, например `192.168.1.50:9100` |
| `Cpcl`   | Часть Zebra / совместимые CPCL | тоже `host:port` |
| `EscPos` | Пока заглушка (не для продакшена) | — |

Если `host:port` не задан, LabelPrint сохранит команды в файл (для отладки), а на устройство не отправит.

## Поля формы

| Поле | Смысл |
|------|--------|
| Название | Как видно в списках печати |
| Протокол | `File` / `Windows` / `Tspl` / `Cpcl` / `EscPos` |
| Подключение | Имя Windows **или** `host:port` **или** папка для File |
| Ширина мм | Ширина ленты/этикетки (должна совпадать с шаблоном) |
| DPI | Разрешение печати (203 типично) |
| Повернуть 90° | Принудительный поворот макета |
| Смещ. X / Y мм | Тонкая подстройка Windows-печати (после HardMargin) |
| По умолчанию | Используется, если в UI принтер не выбран явно |

Кнопки списка:

- **Обновить** — перечитать список из БД  
- **Изменить** — править выбранный  
- **По умолчанию** — сделать выбранный основным  
- **Отключить** — soft-archive (не удаляет историю печати)

## Этикетка 40×58 vs 58×40

- Кухонный шаблон **«Кухня чек 40×58»** — **вертикальный**: ширина **40** мм, высота **58** мм.
- В настройках принтера укажите **ширину 40**, если лента 40 мм.
- Для ценников/сырья часто **58×40** — ширина **58**.

Несовпадение ширины шаблона и ленты даёт обрезание или пустые поля.

## Типичные проблемы

| Симптом | Что проверить |
|---------|----------------|
| «No active printer» | Нет активного принтера или все отключены — добавьте File/Windows |
| Windows: not found | Имя в «Подключение» ≠ имя в Windows |
| Печатает PNG, не железо | Протокол `File` — смените на `Windows`/`Tspl` |
| Пустая этикетка | Нет шаблона у товара / для заказов нет «Кухня чек» |
| Обрезка текста | Ширина принтера и canvas шаблона разные |
| **Верх обрезан, снизу пусто** | Непечатные поля драйвера. Авто-компенсация HardMargin/PrintableArea + запас ~1.5 мм. Если чуть съезжает — в **Принтеры → Изменить** задайте **смещ. Y мм** (верх обрезан → −1…−3; низ обрезан → +1…+3). В драйвере Windows поля = 0. |

Логи: `%LocalAppData%\LabelPrintPro\logs\`

### Если всё ещё мелко / съехало / на две этикетки

1. **Ширина ленты** в LabelPrint → Принтеры = реальная ширина рулона (**часто 58** мм).  
2. Макет «Кухня чек **40×58**» на ленте 58 мм → должен **повернуться** (авто или галка «Повернуть 90°»).  
3. В Windows → принтер → размер бумаги/этикетки **58×40** мм (если такие стикеры).  
4. Если лента правда 40 мм узкая и этикетка высокая 58 мм — поставьте ширину **40** и снимите «Повернуть 90°».  
5. Проверка File-протоколом: PNG в `prints\` — ориентация макета; железо смотрит ещё и драйвер.

## Куда пишутся файлы

| Режим | Путь по умолчанию |
|-------|-------------------|
| File / виртуальный | `%LocalAppData%\LabelPrintPro\prints\` |
| TSPL/CPCL без TCP | туда же (экспорт команд) |
| БД принтеров | `%LocalAppData%\LabelPrintPro\labelprint.db` |
